Mochi Money PWA V2

Upload index.html, manifest.webmanifest, sw.js, icon-192.png, and icon-512.png to the ROOT of your GitHub Pages repository. Do not upload the ZIP itself. Keep existing data by using the same website URL and browser; export a backup before updating. This app uses browser localStorage, not cloud sync. On iPhone use Safari Share > Add to Home Screen. On Android Chrome use Install app / Add to Home screen.
